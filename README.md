# Wedding Invitation

A digital wedding invitation with an RSVP form, built for a real event.

## What it does

A single page invitation with the event details and an RSVP form. Guests submit their response and the hosts get notified, so nobody has to chase people down or keep a list by hand.

## Built with

- Webflow for the page, form and email notifications
- JavaScript

## What I learned

- Building a form that non technical people would actually use on a phone, at whatever moment they open the message
- Browsers block audio autoplay, so the background music has to handle being refused rather than assume it will play
- Sometimes the right amount of custom code is almost none

## Honest note

There is very little JavaScript here. The form handling and email notifications are Webflow's built in features, not code I wrote. `script.js` is the small piece I did write. I am keeping the repo because the project was real and shipped, but this one is a Webflow build, not a JavaScript project.
